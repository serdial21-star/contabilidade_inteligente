# Especificações versionadas — Domínio Sistemas

Esta área preserva a evidência usada pelo conector `DominioConnector`. Ela não
é uma implementação de leiaute e não autoriza gerar arquivos por si só.

O conector somente poderá serializar registros depois que a documentação oficial
completa, a versão aplicável, os mapeamentos revisados e os golden files forem
incorporados e aprovados. Campos, posições, obrigatoriedades, semântica,
codificação e regras de escape ausentes nunca devem ser inferidos.

Consulte [SOURCE_REGISTRY.md](SOURCE_REGISTRY.md) para a proveniência e
[LAYOUT_STATUS.md](LAYOUT_STATUS.md) para o gate de implementação.
