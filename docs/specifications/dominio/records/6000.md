# Registro 6000 — Lançamentos em Lote

Fonte: solução Domínio código 672, capturada em 2026-09-06.

| Campo | Nome | Tipo confirmado | Regra confirmada |
|---:|---|---|---|
| 1 | Identificação do registro | Caractere | Valor fixo `6000` |
| 2 | Tipo do lançamento | Caractere | `D`, `C`, `X` ou `V` |
| 3 | Código do lançamento padrão | Numérico | Informar somente quando houver lançamento padrão vinculado |
| 4 | Localizador | Caractere | Sem regra adicional incorporada |
| 5 | RTT do FCONT | Caractere | Informar somente quando aplicável conforme a especificação oficial |

Significados confirmados do campo 2: `D` um débito para vários créditos; `C`
um crédito para vários débitos; `X` um débito para um crédito; `V` vários
débitos para vários créditos.
