# Assets oficiais Serdial21

Fornecidos pelo usuário para a Phase 02 em 14/09/2026. Origem: pasta `Identidade Visual S21` indicada pelo usuário no Drive H:. Os quatro PNGs foram copiados byte a byte, sem crop, redesenho, recoloração, reconstrução ou geração. Hash SHA-256 de cada cópia foi comparado com seu original e conferiu.

| Arquivo | Uso |
| --- | --- |
| `S21 assinatura principal.png` | Marca horizontal na sidebar e no painel de login. |
| `S21 assinatura vertical.png` | Referência vertical na biblioteca de componentes. |
| `S21 logo simplificada.png` | Sidebar compacta e favicon apontando para o original. |
| `identidade visual S21 v1.png` | Referência de identidade, paleta e tipografia; não carregada como fundo de tela. |

OFFICIAL_BRAND_ASSET = IMPORTED_USER_SUPPLIED. Não há símbolo substituto na nova foundation. `width` e `height:auto` preservam proporção e o arquivo inteiro. Os fundos/margens já presentes nas imagens são preservados; nenhuma versão transparente ou otimizada foi inventada. Os originais somam aproximadamente 4,1 MiB; futuros derivados otimizados devem preservar a marca e ser revisados separadamente.

Os exemplos de produto da prancha são referência visual, não ampliação de contratos: login Google/Microsoft/SSO, nomes/estatísticas, datas e funcionalidades mostrados nela não são automaticamente implementados ou tratados como dados reais.
