OFFICIAL_BRAND_ASSET = IMPORTED_USER_SUPPLIED. Não há símbolo substituto na nova foundation. `width` e `height:auto` preservam proporção e o arquivo inteiro. Os fundos/margens já presentes nas imagens são preservados; nenhuma versão transparente ou otimizada foi inventada. Os originais somam aproximadamente 4,1 MiB; futuros derivados otimizados devem preservar a marca e ser revisados separadamente.

Os exemplos de produto da prancha são referência visual, não ampliação de contratos: login Google/Microsoft/SSO, nomes/estatísticas, datas e funcionalidades mostrados nela não são automaticamente implementados ou tratados como dados reais.
